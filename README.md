# README.md

Este repositório demonstra a construção de um pipeline de dados completo,
seguindo boas práticas de engenharia de dados aplicadas a um cenário corporativo.

## Objetivo
Simular um ambiente real de ingestão, transformação, qualidade, observabilidade
e consumo de dados relacionados a contratos, faturas e pagamentos.

## Arquitetura Geral
- Ingestão batch e via API
- Armazenamento em camadas (Bronze, Silver, Gold)
- Orquestração de pipelines
- Transformações analíticas com dbt
- Validação de qualidade de dados
- Observabilidade e métricas
- Consumo via BI

## Tecnologias Utilizadas
- Python
- Docker
- dbt
- Great Expectations
- Metabase
- GitHub Actions

## Status
Projeto em evolução contínua com foco educacional e demonstrativo.
